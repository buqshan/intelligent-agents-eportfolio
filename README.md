# Intelligent Agents E-Portfolio

Static site (plain HTML/CSS, no build step). Publish with GitHub Pages:

1. Create a public repository, e.g. `intelligent-agents-eportfolio`.
2. Upload the contents of this folder (index.html at the repository root; keep the sub-folders).
3. Settings > Pages > Source: "Deploy from a branch" > Branch `main`, folder `/ (root)` > Save.
4. After about a minute the site is live at `https://<your-username>.github.io/intelligent-agents-eportfolio/`.
5. Put that URL in the Word file (header and title table) in place of the `[github-username]` placeholder.
